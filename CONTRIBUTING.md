# Contributing

Issues and pull requests are welcome, especially reports from other D20
hardware or firmware variants.

Please include the printer model and firmware version, Linux distribution,
BlueZ version, command used, and complete error text. Remove Bluetooth MAC
addresses, serial numbers, hostnames, usernames, and network addresses before
posting logs or captures.

Before submitting a change, run:

```console
python3 -m unittest discover -s tests -v
```

Never attach proprietary APK files, decompiled application source, personal
Bluetooth captures, credentials, or device identifiers to an issue or commit.
